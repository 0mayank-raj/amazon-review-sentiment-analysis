# ⭐ Amazon Review Sentiment Analysis

An end-to-end Machine Learning and Natural Language Processing (NLP) project that predicts whether an Amazon customer review is **Positive** or **Negative**. The application is deployed using **Streamlit** and provides an interactive dashboard for sentiment analysis.

## 📌 Project Overview

This project uses Natural Language Processing (NLP) techniques and a Machine Learning model to classify Amazon customer reviews into Positive and Negative sentiments.

The application allows users to:

- Predict sentiment for custom reviews
- View dataset statistics
- Explore sentiment distribution
- Visualize rating distribution
- Generate word clouds
- Review machine learning model performance
